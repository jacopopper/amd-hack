# Illustrative avatar demo

This `avatar.glb` and transparent `avatar-preview.png` were generated with the
updated Blender/MPFB2 avatar pipeline on 17 October 2026. The isolated test
used a fictional confirmed walker profile and a fictional historical callout.
The GLB imports into Blender with a rig, materials, walker, and callout. It
contains no clinical quote or source-document text.

The figure is a fixed illustrative older woman. It does not depict an actual
person; a walker appears only when that aid is confirmed in the profile.
