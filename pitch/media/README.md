# Video for the pitch site

Put `prototipo.mp4` here: `pitch/index.html` loads it on its own in the "The prototype" slide and starts it when the slide comes into view. Until it exists, the slide shows the "video to be recorded" placeholder.

Content: a screen recording of the app, about 60 s. Home photos → 3D scene with the hazards → nurse review → plan for the family. MP4 H.264, 16:9, 1920×1080, no audio (the voice-over is live).
